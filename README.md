# softethrt vpn 安装说明和文件下载 

SoftEther VPN 是一款免费开源且功能强大的多协议 VPN 软件。它可安装在所有主流操作系统上，包括 Windows、Linux、Mac。
它是 OpenVPN 和微软 VPN 服务器的替代方案，并且可以与 OpenVPN 无缝集成。

SoftEther VPN 内置动态 DNS 和 NAT 穿透功能，通过 HTTPS 建立 SSL-VPN 隧道以穿透 NAT 和防火墙，支持 SSL-VPN、OpenVPN、IPsec、L2TP、MS-SSTP、L2TPv3 和 EtherIP，
具备 RSA 证书认证功能，以及 RADIUS/NT 域用户认证功能。
